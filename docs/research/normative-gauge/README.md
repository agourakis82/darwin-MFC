# Darwin Normative Gauge v1.0

This package studies **normative gauge anomalies**: changes in an executable
normative result caused only by arbitrary local relabeling of otherwise
equivalent witness spaces.

The intended invariant is strict. If each context changes coordinates through
a bijection and every transport is conjugated accordingly, then global-section
existence, holonomy obstruction, disposition, certificate mask, and repair cut
must remain unchanged. Any violation is a machine-verifiable anomaly and the
kernel must refuse.

The package contains:

- an abstract Lean model of local gauges and conjugated transports;
- a constructive coordinate-sensitive analyzer that exhibits an anomaly;
- a Sounio kernel generated deterministically from Normative Holonomy v0.9;
- exhaustive metamorphic checks over every Boolean gauge orbit;
- deliberately gauge-sensitive mutants that must be detected;
- source-fresh native/WASM artifacts, transcripts, evidence, and receipt.

The closed finite domain contains 4,096 ABI states and 32,768 state/gauge
checks. It also checks 1,536 edge transformations and all 4,096 compositions
of two gauge elements over the 64 map triples. The triples partition into nine
gauge orbits. The canonical analyzer has zero detected anomalies; all six
deliberately coordinate-sensitive mutants have constructive counterexamples.

## Candidate contribution

The candidate contribution is a **proof-carrying gauge-anomaly firewall** for
normative transport: an executable result is admissible only when it carries a
complete finite-orbit witness that local representational choices did not
change the result. This is a falsifiable conjunction, not an established claim
of priority.
