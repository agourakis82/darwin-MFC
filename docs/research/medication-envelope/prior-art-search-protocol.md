# Medication Envelope Prior-Art Search Protocol

Status: `OPEN`. This is a discovery protocol, not a completed systematic review, freedom-to-operate analysis, or novelty opinion.

## Candidate contribution under examination

“A medication action created by a professional is checked against a living, provenance-linked executable constraint envelope; each result carries compiler identity, formal proof evidence, uncertainty, and a clinical counterexample.”

No pioneering claim is authorized while this protocol remains open.

## Databases

PubMed, Europe PMC, Crossref, IEEE Xplore, ACM Digital Library, arXiv, WIPO PATENTSCOPE, Espacenet, Google Patents, and INPI Brasil.

## Seed concepts

1. `proof-carrying prescribing`
2. `dose safety envelope`
3. `clinical constraint compiler`
4. `executable guideline provenance`
5. `assurance case medication`

Each seed is expanded with medication, prescription, clinical decision support, runtime verification, formal methods, provenance, counterexample, executable guideline, and assurance-case synonyms. Patent screening must add CPC/IPC classes and family-level deduplication.

## Screening

- Two independent reviewers screen titles/abstracts and then full text or patent claims.
- Include systems joining at least two of: executable medication constraints, evidence provenance, formal proof, compiler/build identity, runtime counterexample, or continuous change impact.
- Exclude ordinary interaction alerts, static dose calculators, generic rules engines, or provenance-only systems unless they anticipate a specific claim element.
- Record reason for exclusion and resolve disagreement by a third reviewer.

## Claim matrix

The final matrix must test each element separately and in combination: living evidence graph, deterministic constraint IR, Sounio/WASM execution, independent proof checking, signed compiler identity, clinical counterexample, scoped credential, and local-only patient context.

## Deliverables

- Reproducible API log.
- Native search exports from IEEE, ACM, arXiv, WIPO, Espacenet, Google Patents, and INPI.
- Deduplicated bibliography and patent-family table.
- Backward/forward citation chaining.
- Claim-by-claim novelty matrix reviewed by qualified counsel before any public originality statement.
