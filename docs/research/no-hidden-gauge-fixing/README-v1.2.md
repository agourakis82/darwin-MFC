# Darwin No Hidden Gauge Fixing v1.2

This research milestone asks a narrower question than medication selection:

> When can a system emit one normative witness without hiding an arbitrary
> coordinate choice?

The candidate answer is a proof obligation. If an input has a non-trivial
stabilizer and that stabilizer moves every admissible output, no deterministic
equivariant selector exists. The system must abstain until an external,
content-addressed observation removes the obstruction. A seed, lexical order,
raw encoding, or implementation accident is not such an observation.

The v1.2 milestone contains:

- a synthetic value-carrying observation receipt with Ed25519 fixture
  signatures, exact provenance, reliability, scope, validity, and revocation;
- a Lean refinement linking receipt authorization, observed values, residual
  symmetry, and model-relative uniqueness;
- a standalone Sounio kernel over all 32,768 raw ABI states, with no singular
  witness export and no TypeScript mathematical fallback;
- a second Sounio kernel and 1,536-case benchmark over six graph families;
- an independent Rust implementation, complete triangle parity, and a blinded
  384-case graph reproduction package;
- source-fresh deterministic native/WASM builds and a fail-closed receipt;
- a dated, claim-by-claim prior-art matrix with blocked searches recorded as
  gaps rather than negative findings.

The strongest scientific candidate is **revocable residual-stabilizer
authorization**: revoking an observation must invalidate every uniqueness proof
that depended on it, restore the residual symmetry when applicable, and force
abstention if a singular equivariant result is no longer justified. This is a
candidate conjunction only; it is not an established novelty claim.

## Scientific boundary

This is an abstract result about deterministic choice under symmetry. It does
not identify a treatment, validate a dose, establish clinical benefit, or
authorize production use. Every receipt in this directory must retain:

```text
clinicalDisposition=REFUSE
clinicalUseAllowed=false
productionAuthorized=false
noveltyEstablished=false
signed=false
```

The synthetic observation artifact has a public test-fixture Ed25519 signature.
It is explicitly ineligible for production trust and does not make the unsigned
research gate a clinical or production authorization.

The mathematical and software ingredients have substantial prior art. The
research candidate is the lifecycle law connecting a revocable observation to
exact residual-stabilizer reduction and mandatory invalidation of dependent
singular outputs. Novelty remains open and requires independent database,
mathematical, clinical-informatics, and legal review.
